# Relational Mathematics Applications (RelMathApps)

> **"Structure exists independently of value. It is relation, not value, that creates meaning."**

This repository contains computational tools and solvers dedicated to **Relational Mathematics**. The primary focus of this module is the study of **Ramanujan-Type Nested Radicals** through a unified structural framework.

## 1. Mathematical Framework: Unified Nested Radicals
This implementation moves away from ad-hoc proofs for specific nested radicals. Instead, it treats radicals as emergent structures generated by arbitrary real-valued sequences. 

The core identity explored is:
$$R_1 = \sqrt{1 + a_1 \sqrt{1 + a_2 \sqrt{1 + \dots \sqrt{1 + a_n R_{n+1}}}}}$$

By focusing on the **Structural Tail ($T^*$)**, the code demonstrates how the stability and convergence of the radical depend on the underlying rhythmic consistency of the coefficient sequence $a_k$.

## 2. Features
* **Generalized Nested Solver:** Computes the root value for any given depth and coefficient sequence.
* **Structural Identity Verification:** Validates the $R_k$ chain to ensure internal consistency of the identity.
* **Equilibrium Finder:** A numerical bisection engine that discovers the "Structural Tail" required for the radical to converge to a specific target value.
* **Sequence Inversion:** Tools to design coefficient sequences ($a_k$) based on desired value progressions.



## 3. Getting Started

### Prerequisites
* **Python 3.8+**
* No external dependencies (pure mathematical logic using the standard `math` library).

### Installation
Clone the repository directly to your local machine:

```bash
# Clone the repository
git clone https://github.com/Flaman55/RelMathApps.git
# Navigate to the algorithm directory
cd RelMathApps/Structural-Primality-Theory
# Run the Ramanujan Unified Radicals solver
python Ramanujan-Unified-Radicals.py

## 4. Formal Verification (Lean 4)

The `lean/` subfolder contains a Lean 4 / Mathlib formalization of the same
unified nested-radical framework, accompanying the paper *"Nested Radicals of
Ramanujan's Type with Arbitrary Coefficient Sequences"* (A. Flamandzki). It
machine-checks boundedness, monotonicity, and convergence for the paper's
general coefficient-sequence recursion, plus original extensions to
previously-open cases: an unbounded linearly-growing family with an exact
limiting value, and existence of convergence for the prime-coefficient case
(`a_k = p_k`), the latter via a general geometric-growth bound built on
Bertrand's postulate. Builds cleanly with `lake build`, zero `sorry`. See
`lean/README.md` for the full breakdown of what is proven, file by file.

```bash
cd RelMathApps/Structural-Primality-Theory/lean
lake exe cache get
lake build
```
